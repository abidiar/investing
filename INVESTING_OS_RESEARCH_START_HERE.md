# Investing OS Research — Start Here

Before doing new Investing OS research, changing a scanner from research findings, or continuing a prior experiment in any chat/work session:

1. Read `research/RESEARCH_GOVERNANCE.md`.
2. Read `research/RESEARCH_STATUS_MASTER.md` for the current cross-topic state.
3. Read the relevant topic status/index, especially `research/options_positioning_research_status.md` for options/OI/gamma work.
4. Read the Google Doc **Investing OS Research Ledger — Canonical** (document ID `1MxHv5HPlr1Ab9A8cb3diPUtBJv6fWgNZwhhrw72zAus`).
5. **Check prior work before designing a new experiment.** Read `research/PRIOR_WORK_REVIEW_STANDARD.md`, then read the relevant file under `research/prior_work/` or create one if the question is new.
6. Read the latest frozen protocol and result files for the specific research branch.
7. Do not begin a new outcome test until the prior-work review is complete and the new protocol is frozen and committed.
8. At completion, update both GitHub master/topic status and the Google Doc ledger.

The reproducible GitHub record controls the scientific verdict. Conversational memory is not a substitute for these artifacts, and a new experiment should not start by rediscovering work already done in the literature or by other credible researchers.
